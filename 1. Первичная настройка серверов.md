## Развертывание и первичная настройка CI/CD-окружения

### Цель
Создать локальную инфраструктуру для GitLab CI/CD с тремя виртуальными машинами: GitLab CE, GitLab Runner и целевой сервер для деплоя. Все узлы располагаются в одной подсети, чтобы воспроизвести базовую цепочку: репозиторий → тесты → сборка Docker → выкладка.

---

### Используемое ISO
- **Ubuntu Server 22.04.4 LTS** (минимальная установка без GUI)

---

### Структура окружения

| ВМ              | Назначение             | Hostname        | IP-адрес       | Роль в пайплайне                     |
| --------------- | ---------------------- | --------------- | -------------- | ------------------------------------ |
| GitLab-Server   | GitLab CE              | GitLab-Server   | 192.168.0.50   | Сервер репозиториев и управления CI  |
| GitLab-Runner   | GitLab Runner + Docker | GitLab-Runner   | 192.168.0.51   | Исполнитель задач пайплайна          |
| Deploy-UB       | Сервер для деплоя      | Deploy-UB       | 192.168.0.52   | Точка выкладки собранного приложения |

---

### Минимальные системные ресурсы

| ВМ              | CPU    | RAM   | Disk |
| --------------- | ------ | ----- | ---- |
| GitLab-Server   | 4 vCPU | 10 GB | 40GB |
| GitLab-Runner   | 2 vCPU | 2 GB  | 20GB |
| Deploy-UB       | 2 vCPU | 2 GB  | 20GB |

---

### Сетевая конфигурация

- Тип подключения: **Bridged (мост)**.
- Подсеть: `192.168.0.0/24` с ручным назначением адресов.
- Настройка выполняется через `netplan` на каждой машине.

Пример `/etc/netplan/00-installer-config.yaml` (подставьте свой интерфейс и IP):

```yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    ens33:
      dhcp4: no
      addresses: [192.168.0.50/24]
      gateway4: 192.168.0.1
      nameservers:
        addresses: [8.8.8.8,8.8.4.4]
```

Примените конфигурацию:

```bash
sudo netplan apply
```

---

### Базовая подготовка узлов

1. **Hostname и /etc/hosts**
   ```bash
   sudo hostnamectl set-hostname GitLab-Server   # замените на имя узла
   echo "192.168.0.50 GitLab-Server" | sudo tee -a /etc/hosts
   echo "192.168.0.51 GitLab-Runner" | sudo tee -a /etc/hosts
   echo "192.168.0.52 Deploy-UB"     | sudo tee -a /etc/hosts
   ```

2. **Обновление системы и SSH**
   ```bash
   sudo apt update && sudo apt upgrade -y
   sudo apt install -y openssh-server
   sudo systemctl enable --now ssh
   ```

3. **Проверка доступности**
   Убедитесь, что все узлы пингуются друг от друга и доступен SSH:
   ```bash
   ping -c 2 192.168.0.51
   ssh user@192.168.0.51 hostname
   ```

После этих шагов можно переходить к установке GitLab CE и настройке раннера.
