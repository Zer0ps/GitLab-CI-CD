# GitLab CI/CD лаборатория

Документация описывает, как развернуть локальное CI/CD-окружение на базе GitLab CE, GitLab Runner и отдельного сервера для деплоя. Окружение разворачивается на трёх виртуальных машинах в одной подсети и имитирует базовую производственную цепочку: репозиторий → тестирование → сборка Docker-образа → деплой на удалённый хост.

## Как использовать репозиторий

1. Последовательно выполните инструкции из раздела **Базовая инфраструктура**, чтобы подготовить виртуальные машины и сеть.
2. На GitLab сервере выполните шаги из **Установка и настройка GitLab CE**.
3. На сервере runner выполните **Установка GitLab Runner** и зарегистрируйте раннер в проекте.
4. Настройте пайплайн и деплой по материалам из **Финальные шаги и интеграция**.
5. При необходимости импортируйте готовый проект и используйте пример `.gitlab-ci.yml` из документации, адаптируя переменные окружения под своё окружение.

## Структура документов

- `1. Первичная настройка серверов.md` — сетевые настройки, минимальные ресурсы и общая схема виртуальных машин.
- `GitLab-CE/Деплой.md` — установка GitLab CE на сервере `GitLab-Server`.
- `GitLab-CE/Настройка GitLab.md` — первый вход, сброс пароля root и импорт существующего проекта в GitLab.
- `GitLab-CE/Настройка GitLab Runner-сервера.md` — установка Docker, GitLab Runner и регистрация раннера для проекта.
- `GitLab-CE/Финальные шаги и интеграция.md` — структура `.gitlab-ci.yml`, используемые переменные и проверки финального пайплайна.

## Быстрые параметры окружения

- **ISO**: Ubuntu Server 22.04.4 LTS
- **Сеть**: 192.168.0.0/24 (статическая адресация, режим Bridge)
- **Хосты**: `GitLab-Server` (192.168.0.50), `GitLab-Runner` (192.168.0.51), `Deploy-UB` (192.168.0.52)
