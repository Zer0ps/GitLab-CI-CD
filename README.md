# GitLab CI/CD лаборатория

Компактная инструкция по развёртыванию локального CI/CD-окружения на базе GitLab CE, GitLab Runner и выделенного сервера деплоя. Окружение разворачивается на трёх ВМ в одной подсети и воспроизводит цепочку: репозиторий → тесты → сборка Docker → выкладка.

## Как использовать репозиторий
1. Подготовьте ВМ и сеть по разделу **Базовая инфраструктура**.
2. Разверните GitLab CE (**Установка и настройка GitLab CE**).
3. Установите Docker и GitLab Runner на втором узле (**Настройка GitLab Runner-сервера**) и зарегистрируйте раннер в проекте.
4. Подготовьте пайплайн и сервер деплоя по материалам **Финальные шаги и интеграция**.
5. При необходимости импортируйте пример проекта и адаптируйте `.gitlab-ci.yml` под свои переменные.

## Структура документов
- `1. Первичная настройка серверов.md` — сеть, минимальные ресурсы, базовая подготовка узлов.
- `GitLab-CE/Деплой.md` — установка GitLab CE на сервере `GitLab-Server`.
- `GitLab-CE/Настройка GitLab.md` — первый вход, сброс пароля root и импорт проекта.
- `GitLab-CE/Настройка GitLab Runner-сервера.md` — установка Docker, GitLab Runner и регистрация раннера.
- `GitLab-CE/Финальные шаги и интеграция.md` — пример `.gitlab-ci.yml`, переменные и проверки деплоя.

## Быстрые параметры окружения
- **ISO**: Ubuntu Server 22.04.4 LTS
- **Сеть**: 192.168.0.0/24 (статические адреса, мост)
- **Хосты**:
  - `GitLab-Server` — 192.168.0.50
  - `GitLab-Runner` — 192.168.0.51
  - `Deploy-UB` — 192.168.0.52
