# Установка GitLab CE

Настройка выполняется на сервере `GitLab-Server`.

## 1. Подготовка системы
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl ca-certificates tzdata openssh-server
sudo systemctl enable --now ssh
```

При необходимости откройте HTTP/HTTPS:
```bash
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable
```

## 2. Подключение официального репозитория
=======
Последовательно выполните команды на сервере `GitLab-Server`.

## 1. Обновление системы

```bash
sudo apt update && sudo apt upgrade -y
```

## 2. Установка зависимостей

```bash
sudo apt install -y curl ca-certificates tzdata openssh-server
```

## 3. Подключение официального репозитория

```bash
curl https://packages.gitlab.com/install/repositories/gitlab/gitlab-ce/script.deb.sh | sudo bash
```

## 4. Установка GitLab CE

Укажите внешний URL вашего GitLab перед установкой:

```bash
sudo EXTERNAL_URL="http://192.168.0.50" apt install gitlab-ce
```

## 4. Применение конфигурации
```bash
sudo gitlab-ctl reconfigure
```

## 5. Проверка состояния
```bash
sudo gitlab-ctl status
sudo gitlab-rake gitlab:check SANITIZE=true
```

После успешной проверки откройте GitLab в браузере: `http://192.168.0.50`.

После установки GitLab будет доступен в браузере по адресу `http://192.168.0.50`.
