# Установка GitLab CE

Последовательно выполните команды на сервере `GitLab-Server`.

## 1. Обновление системы

```bash
sudo apt update && sudo apt upgrade -y
```

## 2. Установка зависимостей

```bash
sudo apt install -y curl ca-certificates tzdata openssh-server
```

## 3. Подключение официального репозитория

```bash
curl https://packages.gitlab.com/install/repositories/gitlab/gitlab-ce/script.deb.sh | sudo bash
```

## 4. Установка GitLab CE

Укажите внешний URL вашего GitLab перед установкой:

```bash
sudo EXTERNAL_URL="http://192.168.0.50" apt install gitlab-ce
```

После установки GitLab будет доступен в браузере по адресу `http://192.168.0.50`.

## 5. Применение конфигурации

```bash
sudo gitlab-ctl reconfigure
```
